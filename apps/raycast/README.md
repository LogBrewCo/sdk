# LogBrew for Raycast

See your LogBrew issues and errors without leaving Raycast. [LogBrew](https://logbrew.co) groups the errors, logs, and traces your apps send into issues you can act on, and you can start on the free plan.

## Commands

| Command | What it does |
| --- | --- |
| Search Issues | Search the unresolved issues of all your projects or one project. Each row shows the level, the event count, and when the issue was last seen. Open an issue in LogBrew or copy its link. |
| Recent Errors | See the error and critical logs one project sent in the last 24 hours. Open the trace in LogBrew or copy the message. |
| New Issues | Show the count of issues first seen in the last 24 hours in your menu bar. Open the newest issues from the menu. |

## Sign In

1. Run any LogBrew command.
2. Choose Continue in Browser. Raycast opens LogBrew in your browser and shows a code.
3. Make sure the browser shows the same code, then approve the sign-in.

You don't copy or paste anything. To sign out, open the actions of any issue or error and choose Sign out of LogBrew.

## Preferences

API URL: keep `https://api.logbrew.co`. Change it only when your team runs LogBrew at another address.
